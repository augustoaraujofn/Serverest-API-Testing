# 🧪 Testes de API com Postman — Serverest

Projeto de testes de API desenvolvido com **Postman**, utilizando a API ServeRest para praticar requisições HTTP, manipulação de dados e validação de respostas.

## 🚀 Funcionalidades testadas

- **Login:** autenticação de usuários.
- **Usuários:** criação, consulta, edição e exclusão.
- **Produtos:** cadastro, consulta, edição e exclusão.
- **Carrinhos:** criação, consulta, conclusão e cancelamento de compras.

## 🛠️ Tecnologias

- Postman
- ServeRest API
- JavaScript
- HTTP (GET, POST, PUT e DELETE)

## ⚙️ Recursos utilizados

- Variáveis de coleção para reutilização de dados.
- Scripts para manipulação de informações das respostas.
- Organização de requisições por funcionalidades.
- Validação de respostas da API.

## ▶️ Como executar

1. Clone este repositório.
2. Importe a coleção JSON no Postman.
3. Configure as variáveis necessárias.
4. Execute as requisições e analise as respostas.

## 🎯 Objetivo

Desenvolver conhecimentos práticos em testes de API e Quality Assurance (QA), utilizando o Postman para explorar funcionalidades e verificar o comportamento de uma aplicação.
